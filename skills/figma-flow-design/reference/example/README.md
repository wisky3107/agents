# Example: Melody Tiles

Ten screens (splash, home, preview, gameplay, pause, revive, result, shop, daily reward,
settings), 28 hotspots, 14 arrows, and a `v2` variant that swaps the chrome for an agy-made
nine-slice kit. Built 2026-10-10/11.

Images are referenced by name and are not stored here. Before rendering, upload files with
these stems: `bg-menu bg-gameplay splash-keyart cover-canon cover-fur-elise cover-moonlight
cover-turkish cover-clair trophy crown chest gem-pile` (art), and for `v2` `btn-cyan btn-pink
btn-green btn-gold btn-glass panel card ribbon tile-black tile-long ic-diamond ic-bolt ic-star
ic-star-empty ic-crown ic-gift ic-gear ic-home ic-cart ic-trophy` (kit). The originals live in
`~/Works/figma-flows/melody-tiles/{art,agy}/web/`.
